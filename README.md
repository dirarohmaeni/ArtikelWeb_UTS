# 💬 Chat Real-Time WebSocket

Aplikasi chat sederhana berbasis WebSocket yang memungkinkan komunikasi real-time antar pengguna tanpa perlu refresh halaman.

---

## 🚀 Fitur
- Chat real-time
- Multi user (bisa beberapa browser)
- Username
- Timestamp (jam)
- Tampilan chat kiri dan kanan
- Bubble chat dengan desain modern

---

## 🛠️ Teknologi yang Digunakan
- Node.js
- WebSocket (ws)
- HTML, CSS, JavaScript

---

## 📦 Cara Menjalankan

1. Install dependencies
```bash npm install```

2. Jalankan Server
```node server.js```

3. Buka di Browser
   ```http://localhost:3000```

## 📚 Penjelasan Singkat

WebSocket digunakan untuk membuat komunikasi dua arah antara client dan server secara real-time. Pada aplikasi ini, setiap pesan yang dikirim akan langsung diteruskan ke semua client yang terhubung.
